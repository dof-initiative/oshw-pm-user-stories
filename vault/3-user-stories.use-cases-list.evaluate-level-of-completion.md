## notes

- Level of completion is the result of an analysis of the project
- want the resulting metric should be more concrete than a technology readiness level
- analysis should include assessment of readiness to complete OSHWA certification
- include type(s) and amount of developer help needed
- search for maturity metrics (not TRL) that are more concrete (maybe OSTRL)
